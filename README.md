# 또르르 구슬 경주

이름을 넣고 시작을 누르면 구슬이 나무 코스(지그재그 경사 → 핀 밭 → 쐐기 → 볼링핀 → 소용돌이)를 굴러 내려가 결승 순서로 당첨자를 뽑는 3D 추첨 게임. 서버 없이 정적 사이트로 배포한다.

설계는 [docs/PLAN.md](docs/PLAN.md), 작업 규칙은 [CLAUDE.md](CLAUDE.md).

## 실행

```
npm install
npm run dev                  # 개발 서버. 폰에서 보려면: npm run dev -- --host
npm run build                # 타입 검사 + 빌드 + gzip 크기
npm run test                 # 단위 테스트
npm run sim -- --seeds 1000  # 헤드리스 시뮬레이션
```

배포는 `dist/` 를 GitHub Pages 같은 정적 호스팅에 올리면 된다(`base: './'`).

## 기능

- 이름 입력: 쉼표·줄바꿈으로 구분, `이름*2` 는 구슬 2개, `이름/3` 은 질량 3배 (최대 30개)
- 셔플(새 시드), 시작, 당첨 기준 1등/꼴찌, 당첨 수 여러 명
- `?seed=8자리16진수&names=...&win=...&n=...&map=...` 링크 공유: 같은 빌드에서 같은 경주가 재생된다
- 선두 추적 카메라(소용돌이에서는 내려다보는 시점), 순위 오버레이, 구슬 이름표
- 맵 선택(`public/maps/index.json`), 맵 편집(JSON을 고쳐 바로 적용), 화질 3단계, 녹화(지원 브라우저만), 스킬(시드 난수 부스트)

## 계획서와 달라진 점

모두 0단계 측정이나 헤드리스 시뮬레이션에서 나온 수치 때문에 바꿨다.

1. **같은 평면의 cuboid 이음새는 튄다.** 1 m/s 로 지나갈 때 최대 9mm 튀었다(Rapier 0.19.3). 그래서 굴러가는 면 하나는 cuboid 하나로 만들고 조각 사이는 낙하로만 잇는다.
2. **단 사이 낙하 40mm → 70mm.** 바닥 충돌체가 30mm 두께라 40mm 낙하로는 아랫단과의 틈이 10mm밖에 안 남아 구슬(16mm)이 낀다.
3. **트랙 폭 150mm → 180mm, 지그재그 3단 → 5단, 경사 3.2°.** 3단·5°는 경주가 약 24초에 끝났다.
4. **쐐기 틈은 32mm 이상.** 22.5mm 틈에서 구슬 둘이 나란히 끼어(아치) 끝까지 못 내려왔다.
5. **첫 단은 쐐기 대신 핀 밭(9-8-9).** 쐐기는 4번 규칙 때문에 한 줄에 다섯 개를 놓을 수 없어 슬롯마다 지연이 달랐고(최대 0.5초), 그 차이가 결승까지 남아 χ² 34가 나왔다. 계획서의 4-3-2-1 볼링핀은 마지막 단에 그대로 있다.
6. **쐐기 줄은 좌우 대칭 + 난간에 붙는 쐐기.** 가운데에만 두면 난간을 타는 구슬이 전부 피해 가 바깥 슬롯이 0.4초 먼저 도착했다. 쐐기는 13개(계획 6~8개). 둘째 단 난간 쐐기의 밑변(19mm)이 바깥 슬롯과 안쪽 슬롯의 균형을 맞추는 손잡이다: 30mm일 때 χ² 8.3~10.0, 22mm일 때 9.2(2,000시드), 19mm일 때 0.6(2,000시드).
7. **소용돌이 앞에 좌우 대칭 홈통.** 폭 180mm로 흩어진 구슬을 한 줄로 모아 테두리 접선 방향으로 넣는다. 한쪽으로만 흐르는 홈통은 출구 쪽 슬롯이 유리했다.
8. **핀은 마찰 0.** 마찰이 있으면 쓰러진 핀 더미에 구슬이 갇혔다. 쓰러진 핀은 미끄러져 내려가 단 끝에서 사라진다.
9. **끼임 안전망은 무작위 수평 방향 0.15 m/s.** 진행 방향으로만 밀면 아치가 풀리지 않았다.
10. **구름 저항은 2 cm/s 이상에서만.** 느릴 때도 걸면 정지 마찰처럼 작용해 쐐기 꼭짓점에 정면으로 닿은 구슬이 그대로 섰다.
11. **쐐기·핀은 절대 좌표 대신 `on`(경사판 id) + `at`(경사판 위 위치)로 적는다.** 경사를 바꿀 때마다 좌표를 다시 계산하지 않아도 된다. 나무 코스 JSON은 `npm run map` 으로 만든다.
12. **나무결 텍스처는 내려받지 않고 canvas에 그린다.** 1024² WebP(약 100KB) 대신 0바이트.
13. **wasm 플러그인을 직접 만들었다**(`scripts/wasm-plugin.ts`, 30줄). `vite-plugin-wasm` 이 Vitest 5 러너에서 동작하지 않았다.

## 하지 않은 것

- 리플레이는 시드 링크 방식만 있다. 기기가 달라도 같은 결과가 나오는지는 확인하지 않았고, 궤적 기록 방식은 만들지 않았다.
- 맵 편집기는 JSON 텍스트 편집이다. 조각을 끌어다 놓는 편집기는 아니다.
- 스킬은 부스트 한 종류다.
- 4단계(WebGPU, Rapier 0.21 이전)는 조건부 항목이라 진행하지 않았다.
- 공정성 튜닝은 구슬 5개 기준이다. 구슬 30개나 `wood-short` 맵에서는 χ²를 재지 않았다(30개·짧은 맵 한 판이 미완주 없이 끝나는 것만 확인).
- 코스 이탈 복귀는 구슬을 가장 가까운 중심선 위로 옮긴다. 소용돌이 입구에서 튕겨 나간 구슬(약 0.2%)은 소용돌이 안으로 돌아오므로 조금 이득을 본다.
- 핀 그림자(블롭)는 구슬에만 있다. 녹화 영상에는 이름표(DOM)가 들어가지 않는다.
